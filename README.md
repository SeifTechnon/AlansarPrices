# AlansarPrices

برنامج سطح مكتب لعرض أسعار مطبوعات الأنصار، مبني باستخدام Python وTkinter.

## المزايا

- عرض أسعار الطباعة ومقاسات الورق.
- اختيار السعر وإبراز السعر والصف والعمود المرتبطين به.
- النقر المزدوج على السعر لنسخه كنص رقمي مناسب للآلات الحاسبة، مثل `7.90`.
- سحب السعر وإفلاته في التطبيقات الأخرى باستخدام `tkinterdnd2`.
- النقر على أرقام التواصل والبريد الإلكتروني لنسخها.
- تغيير لوحة الألوان تلقائيًا بين مرات التشغيل.

## البناء التلقائي

يستخدم المستودع GitHub Actions لبناء نسختين مستقلتين من نفس المصدر:

- **Windows:** ملف `AlansarPrices.exe`.
- **Linux:** ملف تنفيذي باسم `AlansarPrices`.

يبدأ البناء تلقائيًا عند كل تحديث يُرفع إلى فرع `main`، ويمكن تشغيله يدويًا من تبويب **Actions** باختيار **Build AlansarPrices** ثم **Run workflow**.

بعد انتهاء البناء بنجاح، افتح تفاصيل التشغيل ونزّل أحد الملفين من قسم **Artifacts**:

- `AlansarPrices-Windows`
- `AlansarPrices-Linux`

## البناء محليًا على Windows

1. ثبّت Python 3.12 أو إصدارًا متوافقًا.
2. افتح مجلد المشروع.
3. شغّل `build.bat`.
4. ستجد الملف التنفيذي داخل مجلد `dist`.

## المتطلبات

يعتمد البرنامج على مكتبات Python القياسية وTkinter، ويستخدم `tkinterdnd2` لميزة السحب والإفلات. أما `requirements-build.txt` فيحتوي على أدوات البناء والاعتماد الإضافي.

## الأيقونة

ملف `icon.png` هو مصدر الأيقونة، ويُنشئ `make_icon.py` ملف `icon.ico` متعدد الأحجام لاستخدامه عند بناء تطبيق Windows.
